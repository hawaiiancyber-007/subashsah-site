# Subash Sah Portfolio

## Overview
This is a startup-grade, SaaS-ready portfolio site for Subash Sah. Built with Next.js and hosted on Vercel.

## Features
- Live / Maintenance mode toggle
- Admin panel to turn site on/off
- Ocean-style gradient background
- Responsive design
- Assets organized in `/public/assets/images/...`
- Auto-deploy with Vercel on GitHub push
